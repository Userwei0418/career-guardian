## 可迁移字段清单

### 允许进入 staging，供重新清洗

- 企业：历史 ID、名称、状态。
- 岗位：历史 ID、企业 ID、原始/历史规范标题、校招/实习标记、原始地点、JD/要求/职责、投递/详情 URL、发布/首次/最后发现时间。

- 标准城市/省份、岗位族、技能、招聘类型。

- 来源类型与来源岗位 ID。
- 企业行业、类型、规模、总部和官网。

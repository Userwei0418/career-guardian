## 已交付

- 新增 `CareerEvent`、`Evidence`、`GuardianFinding`、`ActionItem`、`DecisionRecord` 和 `Outcome` 六类核心对象。
- Offer、合同和工资条可回链到职业事件；新建 Offer 或合同会在必要时自动建立用户所属事件。
- Alembic 支持空库迁移，并将历史 `CareerCase` 与 Offer 回填为 `decision` 事件。
- 事件及所有子资源执行用户所有权校验；清空账号数据会删除完整事件图。
- HTTP 错误和校验错误统一使用 `error.code/message/status` 响应。
- 一级导航为“今天、机会、决策、权益、收入、成长”，五域均有可访问页面和明确空状态。
- 首页状态来自 `/api/guardian/state`，不再硬编码完成进度；高风险结论和待办行动会形成首要提醒。
- 领域页可嵌入与当前问题相关的知识内容。
- 前端默认通过 Next 同源 `/api` 代理访问后端，代理转发认证、上传和错误响应，并在服务端跟随 FastAPI 路由重定向。

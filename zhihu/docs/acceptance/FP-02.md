## 自动验收

命令：

```bash
./scripts/verify-fp02.sh
```

当前 16 项自动测试全部通过，覆盖：

- 四类固定快照重复解析结果稳定。
- 未审批/未启用来源不能执行真实采集，HTTP/非 allowlist 来源被拒绝。
- 真实 API 请求首次执行限速，超时按配置重试并分类为 `adapter_timeout`。
- 相同快照第二次采集不增加 Raw 记录，任务正确记录重复数。
- 适配器失败会形成 failed 任务，留下 started/failed 运行日志，Raw/Core 均不增加记录。
- 每条显式晋级的 Core 岗位都有 Raw ID、来源 URL、内容哈希和抓取时间。
- staging/raw/core 迁移产生三个互不混表的数据库。
- 市场只读与 Raw Worker 角色的权限边界。
- 脱敏 Pin 备份样本只进 staging，正式模式无人工开关/精确哈希时拒绝执行。
- 备份流式读取使用 UTF-8 增量解码，汉字跨 1MB 读取块时不会被误报为来源乱码。

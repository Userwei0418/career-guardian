# 职护 Career Guardian

职护是面向应届生和职场新人的职业守护产品，围绕机会、决策、权益、收入和成长五个领域，建立从真实岗位到 Offer、合同和首月工资核对的连续证据链。

## 仓库结构

- `zhihu/zhihu-frontend`：职护 Web。
- `zhihu/zhihu-backend`：用户、材料、职业事件与守护结论 API。
- `Pin`：现有招聘数据获取能力的参考实现；后续按数据分层重新设计，不直接作为职护在线业务接口。
- `zhihu/docx`：产品蓝图和按功能点组织的开发计划。
- `zhihu/docs`：架构决策、开发和验收记录。

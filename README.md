# 职护 Career Guardian

职护是面向应届生和职场新人的职业守护产品，围绕机会、决策、权益、收支和成长五个领域，建立从真实岗位到 Offer、合同、首月工资核对和日常收支整理的连续证据链。

## 仓库结构

- `zhihu/zhihu-frontend`：职护 Web。
- `zhihu/zhihu-backend`：用户、材料、职业事件与守护结论 API。
- `zhihu/market-data`：招聘来源治理、浏览器采集、详情 HTML/Raw、标准化、质量门和 Core 晋级。
- `zhihu/docx`：产品蓝图和按功能点组织的开发计划。
- `zhihu/docs`：架构决策、开发和验收记录。
- `scripts`：工作区检查、MySQL 迁移与本地服务启动脚本。
- `.github`：持续集成和依赖更新配置。

## 当前开发状态

`FP-00 可复现与安全基线` 已验收。V2.1 已完成五领域导航、统一职业事件模型和 MySQL 主库收口。机会守护已经形成市场全景、方向分析、岗位推荐/搜索、岗位详情、简历证据分析、收藏/目标、能力路线、简历微调、模拟面试和面试成长的主要闭环。决策守护面向用户从外部渠道获得并主动录入的 Offer，已具备档案、条件化报告、多 Offer 比较、HR 回复与谈薪准备、最终决定历史和跨域流转。我的档案与旧管理中心已合并为统一个人中心；新上传简历保留原件、解析全文、AI 结构化档案和可选的当前版本。

原 FP 编号仅用于追溯历史实现与验收记录，不再作为串行解锁门禁。后续开发先读 [`文档索引`](./zhihu/docs/README.md) 和 [`当前进度与新会话交接`](./zhihu/progress/PROGRESS.md)；早期 V2 开发计划和 PRD 只作历史背景，不再承担当前任务状态。

正式开发、验收与运行统一使用一个 MySQL 实例：`zhihu` 是产品主库，用户数据与清洗后的市场事实（`market_*` 表）都在其中；`pin_legacy_staging` 隔离历史迁移证据，`market_raw` 维护公司招聘渠道、采集任务和采集原文。MySQL 是唯一受支持的运行数据库；历史单元测试夹具不得被当作运行或验收环境。公司与渠道目录、平台模板和兼容解析器均已作为职护自身的版本化资产维护；初始化只读取本仓库资产，不依赖旧项目路径、数据库或服务。

当前主产品目标是完整的成长守护，产品目标始终是“当下的事—过去的果—未来的路”三个平级工作区，开发 Phase 只是工程分段，不是另一个产品目标。“当下的事”的主链路已调整为“用户确认项目总目标 → 材料 → 项目/工作线增量建议 → 人工复核 → 停滞与周/月回顾”。用户在同一入口粘贴会议纪要、方案片段或零散记录；每份原文只保存一次，可关联到独立项目与多条长期工作线，项目级和工作线级分别保存证据与影响建议。Agent 通过受控业务 API 生成结构化建议，不获得任意 SQL 能力；材料入口由 AI 驱动，不再要求用户逐次勾选。对外处理必须有明确的发送范围；模型只生成 `suggested` 候选，确定性程序继续负责证据校验、权限、版本和写入门禁，用户负责正式确认。

成长工作区现使用单层上下文导航：桌面在同一行切换成长模块与“总览、当下的事、过去的果、未来的路”，手机通过“成长守护 · 当前页”菜单完成同样导航，不再叠加第二排胶囊按钮。独立“整合”页不再作为产品入口，旧地址会回到“当下的事”；沟通、汇报、STAR 等能力仍围绕具体事项按需使用。“过去的果”按“作品 → 证据 → 能力 → 筹码”组织为紧凑资产库，新增表单默认收起；“未来的路”按“目标 → 市场温差 → 差距 → 里程碑”组织为职业仪表盘。既有接口和人工确认边界不变；2026-08-27 用户同意按当前体验暂时收口，但这不等同于成长守护的最终产品验收。

2026-08-27 仓库最新树已移除完整参考项目、静态 UI 原型、无关流程图和两个未引用的前端旧副本；市场采集所需企业/学校目录、兼容解析器和历史迁移审计能力已经内化在 `zhihu/market-data`。旧市场库 DDL 只保留为最小测试夹具，运行时不读取任何仓库外参考项目。

管理员可在“管理后台 → 数据准入”查看并调整准入硬条件、阈值和评分权重。修改采用草稿、影响预检、发布三步，已发布版本保留审计记录；质量门不作为用户页面概念展示。机会守护默认每页展示 8 条岗位，支持切换到 12/20 条，并可按职务、公司、城市、专业和招聘类型组合搜索。

本仓库不提交 `.env`、用户上传材料、运行日志、构建依赖或数据库备份。历史导入物只允许在仓库外隔离保管并按受控流程进入 staging。开发和验证方式见 [`开发基线`](./zhihu/docs/development.md)。

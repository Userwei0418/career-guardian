# 前端应用

## 技术栈

- Next.js 14 (App Router)
- React 18 + TypeScript
- TailwindCSS 3.4
- ECharts 6

## 页面结构 (frontend/src/app)

```
app/
├── layout.tsx           # 全局布局 (Header + Footer)
├── page.tsx             # 首页
├── jobs/                # 职位模块
│   ├── page.tsx         # 职位列表
│   └── [id]/page.tsx    # 职位详情
├── companies/           # 公司模块
│   ├── page.tsx         # 公司列表
│   └── [id]/page.tsx    # 公司详情
├── company-lists/       # 公司榜单
│   ├── page.tsx
│   └── [id]/page.tsx
├── analysis/            # 数据分析
│   ├── page.tsx         # 数据总览
│   ├── skills/page.tsx  # 技能图谱
│   ├── clustering/page.tsx  # JD聚类
│   ├── resume-match/page.tsx  # 简历匹配
│   ├── salary/page.tsx  # 薪资分析
│   └── city/page.tsx    # 城市分析
├── admin/               # 管理后台
│   ├── page.tsx
│   ├── crawl/page.tsx       # Pipeline 仪表盘
│   ├── monitor/page.tsx     # 系统监控
│   ├── companies/page.tsx   # 公司管理
│   ├── jobs/page.tsx        # 职位管理
│   ├── files/page.tsx       # 文件浏览
│   └── process/page.tsx     # 处理进度
└── about/page.tsx        # 关于页面
```

## API 客户端 (frontend/src/lib/api.ts)

统一封装：

```typescript
// 泛型请求函数
fetchAPI<T>(endpoint, init?)

// 领域 API 对象
skillsAPI.topSkills(limit, category?)
skillsAPI.categorySkillMatrix(topCat, topSkills)
skillsAPI.aiTrend(days)
skillsAPI.skillSalary(skill)
skillsAPI.skillCombinations(baseSkill)
skillsAPI.skillByCity(topCities, topSkills)

salaryAPI.categoryBoxplot()
salaryAPI.cityComparison(category)
salaryAPI.educationPremium(category)

cityAPI.bubbleData()
cityAPI.categoryHeatmap()
cityAPI.salaryComparison()
cityAPI.campusRank()

clusteringAPI.clusters(nClusters, sampleSize)
clusteringAPI.clusterDetail(clusterId)
clusteringAPI.qualityReport()

matchAPI.uploadResume(file)
matchAPI.matchResume(file, topK)
matchAPI.buildIndex(sampleSize)

companyListsAPI.lists() / .detail(id) / .entries(id)
```

## 本地开发

```bash
cd frontend
npm install
npm run dev
```

API 代理：`next.config.js` 将 `/api/*` 重写到 `http://localhost:8000/api/*`

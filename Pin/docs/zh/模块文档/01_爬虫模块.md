# 爬虫模块

## 模块概述

爬虫系统采用**数据库驱动**架构，支持多公司并发抓取、LLM智能解析、数据标准化入库的完整Pipeline。

## 核心组件

### 1. 入口 (crawler/main.py)

支持三种运行模式：

```
-m cp      # 抓取公司页面 (crawl)
-m cjob    # LLM解析 (process)
-m ingest  # 数据入库
```

可选参数：
- `--company-ids id1,id2,...` 指定公司
- `--all` 全量活跃公司
- `--proxy 代理地址`

### 2. Pipeline 编排 (crawler/pipeline.py)

三步自动化流水线：

```
Step 1: 抓取  -->  Step 2: 解析  -->  Step 3: 入库
main.py -m cp      main.py -m cjob     ingest_cjob.py
```

### 3. 公司抓取器 (crawler/spider_com.py)

基于 Playwright 的浏览器自动化抓取：
- 支持智能滚动加载、分页、点击展开
- 自动处理 iframe、重定向、微信文章
- 抓取结果直接写入 crawl_jobs 表

### 4. LLM 解析 (crawler/spider_data.py + crawler/parsegpt/)

```
原始HTML -> 清洗降噪 -> Markdown转换 -> LLM抽取 -> 结构化JSON
```

多模型路由：
- **豆包 (Doubao)**: 职位列表抽取，Prompt Caching 降本
- **DeepSeek**: 职位详情抽取
- **GPT-4o/Qwen**: 复杂公告解析

### 5. 数据入库 (backend/ingest_cjob.py)

```
LLM解析结果 -> 字段标准化 -> 公司匹配/创建 -> 写入jobs表
```

标准化维度：
- 城市/省份映射
- 薪资解析（年薪÷12, 日薪×22 -> 月薪）
- 学历枚举归一
- 技能标签提取
- 去重键生成

## 数据流状态机

```
crawled -> parsed -> ingested
  |         |
  +-- failed+
```

## 数据库操作 (crawler/crawl_db.py)

- `get_active_companies()` - 获取活跃公司列表
- `save_crawled_job()` - 保存抓取结果
- `get_pending_parse()` - 获取待解析任务
- `update_parsed()` - 更新解析结果
- `get_pending_ingest()` - 获取待入库记录
- `update_ingested()` - 更新入库状态

## 自动解析函数 (crawler/auto_gen_com/)

存储自动生成的站点解析函数库（100+个gen_*.py），支持运行时动态扩展新站点。

## 运行示例

```bash
# 全量 Pipeline
python crawler/pipeline.py

# 指定公司抓取
python crawler/main.py -m cp --company-ids baidu,jd

# 仅LLM解析
python crawler/main.py -m cjob

# 仅入库
python crawler/main.py -m ingest
```

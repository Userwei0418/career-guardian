# 数据库设计

## 1. 核心业务表

### 1.1 companies (公司表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| name | VARCHAR(255) UNIQUE | 公司名称 |
| alias_name | VARCHAR(255) | 简称 |
| logo_url | VARCHAR(500) | Logo地址 |
| website_url | VARCHAR(500) | 官网 |
| career_page_url | VARCHAR(500) | 招聘页面 |
| industry | VARCHAR(100) | 行业 |
| company_type | VARCHAR(100) | 公司类型 |
| size_range | VARCHAR(100) | 规模 |
| headquarters | VARCHAR(255) | 总部 |
| status | TINYINT | 状态：1有效 0无效 |

### 1.2 jobs (职位表)

40+ 字段，覆盖职位全生命周期：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| company_id | BIGINT FK | 关联公司 |
| title | VARCHAR(255) | 职位名称 |
| normalized_title | VARCHAR(255) | 标准化名称 |
| city / province | VARCHAR(100) | 城市/省份 |
| job_category | VARCHAR(100) | 职类 |
| salary_min / salary_max | INT | 薪资范围 |
| salary_unit | VARCHAR(50) | 月/年/日 |
| salary_months | INT | 几薪 |
| education_level | VARCHAR(50) | 学历要求 |
| skill_tags | JSON | 技能标签数组 |
| job_description | MEDIUMTEXT | 职位描述 |
| job_requirements | MEDIUMTEXT | 岗位要求 |
| is_campus | TINYINT | 是否校招 |
| is_intern | TINYINT | 是否实习 |
| is_ai_related | TINYINT | AI相关 |
| employment_type | VARCHAR(50) | 用工类型 |
| apply_url | VARCHAR(500) | 投递链接 |
| source_site | VARCHAR(100) | 来源 |
| status | VARCHAR(50) | open/closed/expired |
| is_active | TINYINT | 是否活跃 |
| published_at | DATETIME | 发布时间 |
| dedupe_key | VARCHAR(255) | 去重键 |

### 1.3 job_sources (职位来源表)

记录同一职位的多个来源渠道。

### 1.4 raw_job_records (原始抓取记录)

保留原始HTML/JSON便于回溯和重跑解析。

## 2. 爬虫相关表

### 2.1 crawl_companies (爬虫公司配置)

替代旧版 INI 配置文件，存储800+家公司配置。

| 字段 | 类型 | 说明 |
|------|------|------|
| com_id | VARCHAR PK | 公司标识 |
| com_name | VARCHAR | 公司名称 |
| json_config | JSON | 抓取配置 |
| is_active | TINYINT | 是否活跃 |
| last_crawl_at | DATETIME | 最后抓取时间 |
| crawl_count | INT | 累计抓取次数 |

### 2.2 crawl_jobs (抓取任务记录)

| 字段 | 类型 | 说明 |
|------|------|------|
| crawl_job_id | UUID PK | 任务唯一ID |
| com_id | VARCHAR FK | 关联公司 |
| job_title | VARCHAR | 职位名称 |
| source_url | VARCHAR | 来源URL |
| raw_html | MEDIUMTEXT | 原始HTML |
| raw_json | JSON | 原始JSON |
| model_json | JSON | LLM解析结果 |
| status | ENUM | crawled → parsed → ingested |
| job_id | BIGINT | 入库后关联jobs.id |

### 2.3 crawl_tasks / crawl_pipeline_runs / crawl_company_status

任务管理、Pipeline执行记录、公司级状态追踪。

## 3. 分析辅助表

### 3.1 skill_stats_cache (技能统计缓存表)

预聚合技能统计数据，避免实时扫描10万+行。

| 字段 | 类型 | 说明 |
|------|------|------|
| skill_name | VARCHAR UK | 技能名称 |
| total_count | INT | 出现总次数 |
| category_distribution | JSON | 职类分布 |
| city_distribution | JSON | 城市分布 |
| avg_salary_min/max | DECIMAL | 平均薪资 |

### 3.2 vector_index_metadata (向量索引元数据)

管理 FAISS 索引文件的版本信息。

### 3.3 resume_match_history (匹配历史)

记录每次简历匹配的详细信息用于效果追踪。

## 4. 索引策略

统一复合索引模式：(is_active, status, [筛选字段], published_at DESC, id DESC)

| 索引 | 场景 |
|------|------|
| idx_default_list | 默认列表排序 |
| idx_city_filter | 城市维度筛选 |
| idx_type_filter | 用工类型筛选 |
| idx_campus_filter | 校招维度筛选 |
| FULLTEXT idx_search | 全文检索(ngram) |
